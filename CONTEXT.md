## Что сделано

1. **Фильтр языка** `src/vp_filter.py`: по содержимому, а не по расширению. `vp_modern` — VP 6+ (`implement … end implement`, `class`, `interface`), `vp_legacy` — VP 5 / Turbo Prolog (разделы `domains`/`predicates`/`clauses`/`goal`), `generated` — служебные файлы IDE (`VPITools.pro`, `goal$000.pro`, `.pack`, `.ph`), `broken` — намеренно ошибочный код из тестов анализатора, `other` — всё прочее. Каждое решение фильтра по 382 файлам GitHub проверено вручную по первым строкам.
2. **Удален мусор:** 202 файла не на Visual Prolog из GitHub-выборки, 104 файла Rosetta Code на обычном Прологе, `data/processed` целиком, старые скрипты (`download_rosetta.py`, `download_wiki_archives.py`, `merge_datasets.py`, четыре скрипта wiki).
3. **GitHub:** оставлено 180 файлов (136 современный VP, 44 VP 5) в `data/raw/github/files`, к ним `manifest.csv` — репозиторий, путь, диалект, ссылка.
4. **Учебные примеры** заново скачаны и перекодированы в UTF-8 (`src/collect/download_textbooks.py`): де Бур для 7.3 и 9 (ссылка `/9/`, а не `/90/`, как было в старом скрипте), Costa «Tyros» для 7.1 и 7.3, материалы к книге Скотта по ИИ. Де Бур для 7.2 не взят: совпадает с 7.3 на 346 из 360 файлов.
5. **Wiki Visual Prolog** (`src/collect/parse_wiki.py`): все страницы через API MediaWiki вместо пяти выбранных вручную; для каждого блока `<pre class="visualprolog">` сохраняются страница, раздел и абзацы пояснения перед ним. Английская wiki — 1077 блоков с 80 страниц, русская (wikiru) — 696. Китайские переводы пропущены (код тот же).
6. **Учебники в PDF** (`src/collect/parse_book_pdfs.py`): Costa «Visual Prolog for Tyros» 7.3 — код определяется по машинописному шрифту, отступы восстановлены по координатам строк (358 пар); де Бур «A Beginners' Guide» 7.2 — код набран тем же шрифтом, что и текст, поэтому строки кода узнаются по виду (506 пар). Сами PDF в репозиторий не кладутся.
7. **Лабораторные ТулГУ** (Visual Prolog 11, `src/collect/import_tulsu_labs.py`): 5 программ (лабы 2–5) и 51 пара «раздел + пояснение → фрагмент кода» из разборов кода ЛР1–ЛР5. Автор, преподаватель, группа и номер варианта в данные не переносятся.
8. **Датасет** `src/build_dataset.py` → `data/dataset/`: `github_code` (147), `textbook_pairs` (2052), `textbook_code` (416), статистика — `STATS.md`. Очистка: шапки и автокод IDE вырезаются, отсев коротких (файлы < 40, пары < 10 значащих символов) и длинных (> 20 000), удаление повторов.
9. **История git переписана** (22.10.2026): из всех коммитов убраны персональные данные лабораторных — прежние пути и сообщения с фамилиями; исправлены цифры в сообщении коммита о фильтрации GitHub.
10. **`.gitattributes`:** `.pro`, `.cl`, `.i` отмечены как Prolog — в языках репозитория теперь только Prolog и Python. Переводы строк — LF.
